# 🍽️ Proyecto 1: Sistema de Gestión para Restaurante

Programa interactivo en consola diseñado para gestionar la operación diaria de un restaurante, controlando desde el menú hasta el inventario.

---

## 🚀 Funcionalidades

* **📋 Menú de Productos:** Administración y consulta del menú (platos fuertes, bebidas, etc.).
* **🪑 Control de Mesas:** Manejo de disponibilidad y asignación.
* **📝 Gestión de Pedidos:** Levantamiento de comandas y cálculo del total a pagar.
* **📦 Control de Inventario:** Descuento automático de stock al confirmar consumos.
